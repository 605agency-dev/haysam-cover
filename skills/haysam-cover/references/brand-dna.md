# Brand DNA (hidden consistency)

## Canvas
- Master 1080 × 1920 (9:16, stories/reels). Feed version 1080 × 1350 (4:5) = y 285–1635 of the master; the kit makes it automatically.
- Key content (headline, offer, CTA, lockup) inside y 285–1635. Lockup at y 330.

## Logo
- Mark + caps **HAYSAM** wordmark. Variants on the kit page: `Ink` (light bgs), `Yellow+Ink`, `Yellow+White` (dark bgs), `White` (photos).
- Small and centred by default (52 px high). With a tool: `HAYSAM × [official tool logo] Tool name`.

## Colour tokens
| token | hex | use |
| --- | --- | --- |
| bg/light | `#E5E9FF` | lavender canvas |
| bg/board | `#F6F7FF` | near-white canvas |
| bg/dark | `#270601` | night/cinema covers only |
| ink | `#58160C` | Haysam text, lettering |
| accent/yellow | `#FEE252` | stickers, glow core |
| accent/orange | `#DF3909` | glow trail, cursor |
| offer/sky → cyan → blue | `#9EE8FF` `#2CD3F3` `#1B7BFF` | offers and prices only |
| lettering ink metal | `#270601 → #58160C → #A0301A` | gradient headlines (`'inkMetal'`) |

These colours are for covers **without** an image. On image covers the picture sets every colour (canvas, fades, headline, chip); Haysam shows only through the logo lockup, the tool logo and the font. Buttons may keep brand colour. One accent per post.

## Type
Mood fonts change every post (see `spec.md`). Headline big (110–230 px), max 2 lines, tight leading (88–95%). Inter only for chips and labels. No small meta text.

## Signature details (use 1–2 per cover, not all)
- Comet glow: crisp yellow head, soft orange trail, aimed at the hero.
- Figma selection box + named cursor ("haysam").
- Mono sticker tilted −4°.
- Pop button: same-hue rim and glow, never a dark outline.
- Liquid-glass CTA for offers.
- Gradient lettering with a thin top sheen (no bevels, no WordArt).
