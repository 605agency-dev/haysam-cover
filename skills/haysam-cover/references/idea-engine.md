# Idea engine

Style comes from meaning. The user gives words + tool + one sentence of direction; you invent the idea.

## Step 1 · Insight → metaphor

- **Insight**: what the learner gets, in their words. "Saytni kod yozmasdan o'zing yig'asan." Not "Claude tutorial".
- **Metaphor**: one concrete visual that a stranger understands in half a second while scrolling. An object, a scene, a UI moment. Never a collage of icons.

Good metaphors for an education brand: a lesson card or notebook page, a key/padlock (unlock a skill), a remote/keycap (press to start), a ticket (offer), a letter (personal news), a before/after split (transformation), a stack of stages (process), a person using the tool in a studio (human face for a new lesson).

## Step 3 · Rotation rule

Read the last 3 COVER LOG rows. The new cover differs from each of them in all four:

1. **Layout** (letter)
2. **Background** (plain / dots / lines / grid / tiles / photo / wash / dark)
3. **Mood font** (brand / news / future / loud / cinema / premium / play)
4. **Accent colour** (one per post: tool colour, topic colour, Haysam yellow, offer sky…)

If the first choice breaks the rule, take the second. Log the new cover with `log: {…}` in the SPEC.

## Step 4 · Copy

- Headline: 2–5 words, max 2 lines, Uzbek Latin, keep the user's meaning. Use caps for news/loud/future, sentence case for premium/play.
- Use `'` (U+2018/U+02BB style apostrophes are fine) consistently: o'zing, so'm, qo'shimcha.
- Chips: 2–3 words each, max 3 chips. Price and lesson number become the hero, not a chip.
- CTA (optional): one verb. Boshlash, Ko'rish, Olish, Yozilish.
