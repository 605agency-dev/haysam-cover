Savollar

    

      
API kalit kerakmi?
Yo'q. Figma va Higgsfield'ga o'z profilingiz bilan kirasiz. Plagin hech qanday kalit yoki parol so'ramaydi.

      
Muqova qayerda paydo bo'ladi?
Faqat siz bergan Figma faylda, Haysam Covers sahifasida. Fayl bo'lmasa, Claude sizning draftlaringizda yangisini ochadi. Haysam namuna fayli faqat o'qiladi.

      
Rasm qaysi model bilan chiziladi?
Higgsfield'dagi Nano Banana 2 bilan. Kreditlar sizning Higgsfield hisobingizdan yechiladi. Video faqat siz alohida so'rasangiz qilinadi.

      
Muqovani keyin o'zgartira olamanmi?
Ha. Hammasi oddiy Figma qatlamlari: matnni tahrirlaysiz, rasmni almashtirasiz, tugma rangini o'zgartirasiz. 4:5 versiya 9:16 masterdan yangilanadi.

      
Nega har safar boshqa layout chiqadi?
Claude oxirgi uchta muqovani faylning COVER LOG jurnalidan o'qiydi va layout, fon, shrift yoki rangni takrorlamaydi. Bitta layoutni xohlasangiz, brifda ayting.

      
Qaysi toollar logosi bor?
Claude, ChatGPT, Gemini, Google Veo, Figma, Notion, Canva, Photoshop, Perplexity, ElevenLabs, Suno, Telegram va boshqalar. Yangi tool uchun Claude rasmiy SVG faylni topib kitga qo'shadi.

      
O'z rasmimni ishlatsam bo'ladimi?
Ha. Brifda rasmni bering: Claude uni slotga joylaydi yoki uslubni saqlab qayta chizdiradi.

      
Matn qaysi tilda bo'ladi?
Brifni qaysi tilda yozsangiz, muqova o'sha tilda. Asosiy til o'zbekcha lotin.
